# Contactos publicados

Aquí el panel (`/panel/`) publica un archivo `<id>.vcf` por persona. Esa URL
se graba en el segundo registro de cada tarjeta (método M12 B+) y es la que
abre el iPhone.

**Atención:** si este repositorio es público, todo lo que esté en esta carpeta
queda visible para cualquiera. Ver `docs/PANEL.md`.
